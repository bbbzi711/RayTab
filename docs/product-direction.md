# RayTab 产品定位与本轮目标

2026-10-03，按用户明确方向：以网站图标管理为核心，简洁、流畅的开源新标签页。图标基本覆盖常用网站即可；优先提高整理效率、显示一致性和本地重载体验。

## 产品边界

- 核心任务：添加、编辑、排序、分组、文件夹及右键管理网站图标。
- 辅助能力：搜索、时钟和壁纸；现有私密保护、备份、导入及用户配置的同步保持可用。
- 数据原则：默认本地保存，无需账号或自建服务器；不向图标服务发送完整网址、书签列表或私密内容。
- 交互原则：默认好用、控件对齐、状态反馈清楚；按需展示裁切、上传、同步维护等次级操作。
- 实现原则：沿用 WXT、React、Zustand、RHF、Zod、Radix、idb 等已接入机制，不增加同职责框架。

## 本轮实现

1. 网站图标优先从官网声明的 Icon、Apple Touch Icon、Manifest、Windows Tile 和网站自身的结构化 Logo 获取，并补查通用 Touch Icon 路径。最后以官网 favicon 兜底。不接入第三方品牌目录、应用商店或 favicon 代理，不逐站维护替代素材。需要更高清或特定样式时由用户上传。
2. SVG、小尺寸图标和动画保留原文件；超过 512px 的静态 PNG、JPEG 和 WebP 图标在统一保存入口按比例缩小，保持格式、透明度与完整构图，仅采用体积更小的结果，减少本地存储及备份体积。不放大小图，不批量改写已保存资源；用户主动裁切除外。获取失败保留当前图标与草稿。
3. 品牌标记、底色和留白一并处理：完整图片保持原样，透明标记显示在不透明底色上，用户上传或手动设置优先；显示已保存的自动图标时不再用内置品牌图覆盖。
4. 编辑入口紧凑明确，只保留网站、文字、上传三种来源；导航对象通过右键和键盘管理。设置保持统一控件节奏，语言与安全有正常归属。
5. 图标与壁纸使用现有本地保存入口；新标签页打开不发起图标服务查询，不为显示建立第二套用户数据。

本轮不增加小组件商店、账号服务或用户自部署要求，不迁移实际用户数据，不提交、推送或发布。

## 参考取舍

| 来源           | 借鉴内容                             | RayTab 的取舍                                            |
| -------------- | ------------------------------------ | -------------------------------------------------------- |
| Bonjourr       | 对象右键编辑、自动获取与精选素材配合 | 使用已有成熟交互，不接入其自建服务                       |
| Renewed Tab    | 在线目录本地匹配、图片缓存           | 用户图片沿用已有 IndexedDB 资源入口                      |
| Tabliss、Mue   | 任意域名通过通用来源获取             | 复用官网声明的图片，不为新增网站加专用代码               |
| GoTab          | 精选矢量图标和品牌底色、服务端资源库 | 借鉴显示数据；接口稳定性与第三方使用范围未确认，暂不接入 |
| Anori、Toby 等 | 全局偏好有归属、按任务展开表单       | 保留必要设置与数据任务，降低首屏复杂度                   |

来源与可核实范围见 `research/newtab-open-source.md`、`research/newtab-products.md` 和 `ui-reference.md`。GoTab 的部署资源说明见[官方仓库](https://github.com/dengxiwang/gotab-personal)。

## 完成条件

- 新域名可以通过官网图标获取保存，刷新和离线重载仍显示本地图片。
- 不请求第三方图标目录、应用商店或 favicon 代理；只请求所填网站及其声明的图标资源、Manifest 和通用 Touch Icon / favicon 路径。私密空间继续仅在用户主动获取时请求官网，用户上传的图片不被自动获取覆盖。
- 低清、损坏、占位图、超时和保存失败有明确处理，不覆盖已保存图片，不丢失草稿。
- 网站编辑、右键移动/删除确认、文件夹与分组拖拽、设置保存重载在真实扩展上下文验收。
- 截图检查编辑与设置布局、明暗主题、窄屏；类型、相关逻辑测试、格式以及 Chrome/Firefox 构建通过。
- 国内运营商网络质量单独记录；模拟官网响应只能证明获取与保存逻辑，不能证明真实官网的网络可靠性或原图质量。

实际完成结果记录在 `modernization-validation.md`，不以目标清单或打包成功代替交互验收。
