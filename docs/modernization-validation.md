## 2026-10-23 简化 WebDAV 服务器地址

同步表单改为“服务器地址”，坚果云直接粘贴 `https://dav.jianguoyun.com/dav/` 即可，省略末尾 `/` 也可用。目录地址由共享解析入口补上 `raytab.json`，GET／PUT 均访问备份文件，不再请求目录；已有完整文件地址保留原目标。等价的服务器地址与文件地址共用同步目标标识，修改填写方式不会丢失基线、冲突和成功状态；无效的已保存地址仍可编辑修正。

参考 [Floccus 的服务器地址与文件路径组合](https://github.com/floccusaddon/floccus/blob/develop/src/lib/adapters/WebDav.ts)以及 [All API Hub 的坚果云目录探测修复](https://github.com/qixing-jk/all-api-hub/pull/982)。RayTab 使用默认文件名简化配置，保留文件 GET／PUT 与 ETag 条件写入，没有增加目录 GET 或以无条件覆盖规避冲突。

验证：291 项单测、9 项相关 Chromium 扩展回归、TypeScript、Chrome MV3 与 Firefox MV2 构建通过。扩展回归将坚果云地址转发至隔离的本地 WebDAV 测试服务，覆盖直接粘贴服务器地址、无末尾斜杠、首次创建、刷新重载、已有文件地址、401／403、配置草稿与同步互斥；未操作真实云账号或日常 Chrome。

## 2026-10-21 坚果云连接诊断

用户授权检查已保存的连接配置后，确认其地址为 WebDAV 根目录，而非备份文件。沿用该连接进行只读请求：目录 GET 返回 403，深度为 0 的 PROPFIND 返回 207，目标文件 HEAD 返回 404。认证可用；目录禁止 GET 被原有统一错误误报为认证失败。检查没有修改真实连接配置或云端文件，未导出凭据。

表单与 WebDAV 适配器现在共用文件地址校验，拦截根目录及以 `/` 结尾的目录地址，已有错误配置也会在联网前给出修改提示；增加完整文件地址和坚果云示例。HTTP 401 与 403 分别显示认证被拒绝、服务器禁止操作，并保留受控状态码和请求方法，不保存响应正文或凭据。

随后出现的 HTTP 410 经只读复核，来自已保存的 `/tab` 地址，缺少坚果云 WebDAV 必须的 `/dav/` 前缀。同一账号访问 `/dav/raytab.json` 返回 404 `ObjectNotFound`，根目录属性查询仍返回 207；未将 410 当作文件不存在。补充仅针对坚果云已知域名的路径前缀校验，其他 WebDAV 服务仍可使用自己的路径。

本轮 TypeScript、25 个文件的 282 项单测、6 项相关 Chromium 扩展回归、全仓格式检查、Chrome MV3 与 Firefox MV2 构建及差异检查通过。新增扩展回归覆盖目录或错误前缀地址提交失败时保留草稿、首次文件创建、刷新后条件更新，以及 401／403 的分类和失败状态。真实坚果云写入尚未执行；未提交代码。
