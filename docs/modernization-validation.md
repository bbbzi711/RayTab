# RayTab 当前改造与验收

日期：2026-10-03。本记录描述改造与发布前验收，使用隔离数据库和浏览器配置，未访问用户真实同步账号。远端最终检查与发布状态以 [GitHub Actions](https://github.com/bbbzi711/RayTab/actions)、仓库标签及 Releases 为准。

## 当前界面

此前按单一产品复刻的界面已替换。当前定位为“以网站图标管理为核心、简洁流畅的开源新标签页”，见 [产品定位](product-direction.md)、[界面设计](ui-reference.md) 和 [逐项设置决策](research/settings-decisions.md)。

- 调研 13 款产品：iTab、Infinity、WeTab、Momentum、Toby、Group Speed Dial、start.me、Tabliss、Bonjourr、nightTab、Anori、Renewed Tab、Mue；依据分别来自官方文档、源码、开发者说明与部分在线实看，不表示全部安装验收。
- 实看 iTab、Bonjourr、Tabliss、Mue 在线设置；Renewed Tab 演示证书日期错误，未绕过。研究截图在 `artifacts/research/newtabs/`，真实用户反馈的日期、处理状态与证据层级在两份[产品](research/newtab-products.md)[研究](research/newtab-open-source.md)中。
- 设置改为 840×640px 居中工作区，淡灰导航、白色内容、统一强调色与深色语义变量。扁平分节，去除深色图标方块和多层背景卡片。
- 六类为通用、图标与布局、壁纸与主题、搜索与时钟、同步、数据与备份。语言、打开方式、分组栏与私密保护归入通用；关闭设置不改变桌面布局或简洁模式。
- 删除五时段问候 JSON 全流程、六部件文字颜色及模型字段、逐行继承状态/按钮和重复圆角预设。私密偏好合为一次确认的整体恢复，网站、分组与密码保护保留。
- 图标编辑 600px，96px 最终预览放入图标区，网址/名称/位置恢复完整宽度，网站/文字/上传三来源；仅展开当前来源参数。获取、上传、裁切与配色保留，保存主操作在右下。
- 网站及文件夹移除右上角“…”；支持右键、菜单键与 Shift+F10，网站菜单收敛为编辑、移动、删除。存入位置直接显示分组名。
- 图标取消透明底，图片默认白色实底、文件夹实色底板。社区目录包含 667 条、565 个域名、827 个本地 SVG，另有国内精选素材；产品域名与路径优先于母公司图标。普通空间按需读取 SVGL 公开目录，在本地匹配新收录品牌，不向目录发送域名；七天缓存、失败后一小时重试，新增网站无需逐个改代码打包。未匹配网站尝试声明图标／PWA 和 Vemetric 公共服务，仅向后者发送域名；私密空间及内网不走第三方。位图优先 128px 以上，64／96px 为备用，32px 原图只作最后回退，SVG 按最大 256px 保存，不放大低清位图。
- 新用户默认进入图标导航，进入简洁模式的操作放在首页右键菜单；已有用户选择保留。普通空间新网站输入有效网址后离开字段会自动获取，私密空间仍需主动操作。手动选择或裁切不被旧请求覆盖；编辑网址和重新获取失败保留已有图片。未保存图片提示“保存后可离线使用”，持久图片才提示“已保存”。
- 图标底色改为十种常用颜色，保留自动和自定义；换底色保留彩色 Logo 原色，单色标记自适应对比度。Gemini 改用 Google 原始品牌素材并本地打包，区分 Google 搜索及其他产品。
- 数据页先选导入、导出或恢复，再进入对应任务。文件、选项、错误与草稿在返回或切栏目后保留；进入/返回恢复键盘焦点。壁纸与数据复用同一个文件选择控件。
- 同步页先显示真实配置状态，按需展开连接。保存失败保留输入；读取失败有重试。私密空间锁定时禁止保存包含私密空间的连接配置，并要求先解锁，避免输入密码被静默舍弃。

## 技术与数据边界

| 职责         | 当前实现                                                                      |
| ------------ | ----------------------------------------------------------------------------- |
| 共享状态     | Zustand 覆盖首页、Popup、设置、导航和私密会话；保存以 Repository 事务结果为准 |
| 保存型表单   | React Hook Form + Zod resolver；即时开关/滑块沿用即时保存和失败重试           |
| 国际化       | i18next/react-i18next，稳定语义键、插值与复数                                 |
| 通知         | Sonner 普通通知、就近字段错误、Radix 危险确认                                 |
| 本机同步互斥 | 原生 Web Locks；远端修订、ETag/SHA 和本地事务继续由业务层负责                 |
| 裁切         | React Easy Crop，显式确认后生成新素材；保留 Logo 内部白色像素                 |
| 扩展回归     | Playwright 隔离 Chromium 扩展配置；Firefox 独立实际扩展冒烟                   |

完整改造新增并接入 Zustand、React Hook Form／Zod resolver、i18next／react-i18next、Sonner、React Easy Crop 和 Playwright，依赖清单与 pnpm 锁文件同步更新；最后一次图标覆盖和产品定位迭代没有再增加或升级依赖。本地验收没有手工迁移或清理真实用户数据库。壁纸缓存复用 idb 与现有数据库：物理版本 3 新增派生缓存表，验证保留旧状态、图片原始字节和加密信封。启动入口先恢复普通空间壁纸，首张无淡入，换图失败保留旧图；私密和未保存预览不写入普通启动缓存。缓存写入失败有单独提示。退役展示字段仍在既有 Zod 加载、解锁和导入边界被剔除，当前运行路径不保留旧模式。

## 验证限制

- Firefox 为 Nightly 155.0 基础验收，未覆盖最低声明版本 140 的全部交互。测试客户端退出有既有 mozprofile 清理告警；功能断言与退出码通过。
- WebDAV/GitHub/Gitee 使用隔离模拟响应与协议测试；未验证真实云账号。远端检查与标签发布结果见 [GitHub Actions](https://github.com/bbbzi711/RayTab/actions)。
- 构建仍有超过 500 kB 的共享 JS chunk 提示，当前约 532 kB，未调整阈值隐藏；完整扩展约 4.77 MB（未压缩），图标按使用加载，普通构建不联网更新目录。
- 实测公共 API 的 SVG、原尺寸位图及默认占位元数据；国内运营商网络没有实测，不能保证服务在所有线路可达。
- 图片不会自动抠白或裁掉 Logo；用户可显式裁切。没有素材的站点采用名称首字，不能把它称为已获取官方图标。
- Firefox ZIP 未签名。浏览器已加载的扩展需在扩展管理页重新加载。

## 发布前检查

首次 Linux 远端回归发现图标测试在点击保存后约 4 毫秒就重载，追踪快照显示弹窗和保存加载状态仍存在，打断了尚未完成的图片处理或事务写入。已改为等待保存成功关闭弹窗后重载，保留图片像素、文字来源、底色与重载后的全部断言；没有增加超时、重试或修改保存业务。对应失败运行记录为 [主分支检查](https://github.com/bbbzi711/RayTab/actions/runs/37121703408) 与 [首次发布检查](https://github.com/bbbzi711/RayTab/actions/runs/37121703699)。

发布前还统一了上游 SVG 的 LF 换行和行尾空白，再生成内容哈希、目录和索引。Git 暂存字节核验覆盖 691 条品牌记录、852 个素材引用、850 个独立文件，全部哈希一致，避免 Linux 检出时换行转换破坏完整性校验。

## 国内常用网站图标修正（前阶段记录）

此前 128px 硬门槛误拒绝京东、腾讯官网等 96px 原图。现保留 64／96px 可用原图，继续优先更大的声明图标及矢量。贴吧官网与公共服务只有 32px favicon，改从验证包名的官方应用详情获取 256px 原图，与另外 23 个国内应用域名一起打包至现有本地品牌目录。编辑预览直接显示官方完整图片；京东、拼多多、腾讯视频采用官网稳定标识，避免官方应用商店的活动推广素材。不透明应用图片隐藏无效底色设置，尚未取得图片的编辑预览用中性占位图标。

本轮验收：219 项单测通过；4 项受影响的 Chromium 扩展回归通过，其中国内品牌覆盖检查逐个保存 24 个域名并离线重载。实际 Firefox 155 临时配置完成 10 项检查，贴吧 PNG、京东原始 ICO、拼多多官网图片在离线重载后正确显示。实际效果已检查 `artifacts/acceptance/regional-brand-icons.png` 和 `artifacts/acceptance/tieba-editor.png`；Chrome／Firefox 构建及 ZIP 完整性、产物字节一致性检查通过。Firefox 首次受限运行被系统阻止创建子进程，改在隔离临时配置中获得授权运行后通过。
