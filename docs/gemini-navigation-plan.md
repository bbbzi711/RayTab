# 首页布局与视觉约定

用户已确认：以 `raytab-home.html` demo 的整体布局和操作逻辑为蓝本，采用原项目的壁纸、毛玻璃、圆角和轻字重视觉。保留视觉语言不等于保留旧页面结构。

## 页面结构

- 左侧从上到下：Logo、分组列表、添加分组；底部为单个普通/私密空间切换入口和设置。
- 分组采用图标和名称，长名称截断并可查看全名；列表可滚动。不要只显示前两个字。
- 主区域始终按整个窗口居中，侧栏悬浮显示且不占主页宽度，依次为时钟与日期、搜索、网站与手动文件夹。
- 主区域不显示横向分组栏，不常驻新建/整理工具条。网站末尾保留添加网站。
- 网站右键编辑、移动、复制、删除；空白区域右键添加网站、新建文件夹、进入整理、打开设置。
- 手机端延续左侧分组栏，主区域合理换行，不堆叠底部工具条。

## 视觉与实现边界

- 尺寸和动效可根据整体比例调整，不把旧侧栏宽度当成不可改变的要求。参考 demo 的桌面 76px、手机 56px 侧栏及更舒展的时钟/搜索/网格间距。
- 保留已有背景与用户外观选择；不导入 demo 示例网站，不复制假搜索、演示存储或说明文案。
- 仅保留一套导航结构。侧栏分组仍处于同一个拖放上下文，确保网站/文件夹跨组移动有效。
- 保留现有数据模型、私密保护、单次迁移和直接打开原网址的行为。
- 验收以真实桌面/窄屏截图、分组与空间切换、右键菜单、键盘及跨容器拖动为准，构建通过不能替代这些检查。
