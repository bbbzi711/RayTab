# 图标与壁纸启动

## 网站图标

网站／文字／上传仍是三种来源。自动图标优先显示本地精选矢量品牌，即使此前保存过官网位图，也无需改写数据或联网即可使用新的显示规则；已有资源继续保留。用户上传和带有明确裁切标记的构图优先，不被品牌素材覆盖。透明像素显示在统一的不透明底色上，品牌原有颜色不会被背景色染色。未知网站使用统一中性底色，不按域名随机配色。

SVGL 社区目录生成本地索引，剔除内嵌位图的 SVG 后，本次矢量快照包含 664 条、563 个域名、824 个 SVG。国内常用网站另外从腾讯应用宝的结构化详情取得官方应用图片；带营销文字的图片改用官网长期标识（京东、拼多多、腾讯视频），按包名确认应用并记录发布者和素材，再接入同一品牌索引。目前覆盖 24 个域名、23 张官方素材（20 张 256px PNG、2 张官网 PNG、1 张 96px ICO），包括贴吧、京东、天猫、QQ邮箱、百度网盘、腾讯视频等；这不是全部网站的覆盖率承诺。完整应用图片按原有背景铺满图标，不再套缩小的 Logo 留白，也不显示对不透明图片无效的底色设置。常用品牌保留必要的默认底色和黑白对比处理；其他域名按目录的精确域名和产品路径匹配，不将任意子域名套成母公司图标。ChatGPT 等应用域名使用小型别名表，不维护重复的 Logo 库。

`public/brand-icons/catalog.json` 记录来源、品牌规范链接和 SHA-256；`third-party/svgl-LICENSE.txt` 保留上游许可，商标权归各自所有者。独立图片资源才进入目录，脚本、外部依赖等不收录。维护者运行 `node scripts/update-brand-icons.mjs` 更新离线快照；可用 `node scripts/update-brand-icons.mjs --apps-only` 只更新应用图片；`--local-only` 离线重建当前快照并剔除不符合素材要求的 SVG，映射记录在 `scripts/app-brand-sources.json`。应用素材记录包名、发布者、详情页、原图和哈希；商标权归发布者，不能按 SVGL 的许可重新授权。日常构建不联网；运行时不请求应用宝，也不需要自建服务器。

主动获取图标统一经过 `resolveWebsiteIcon`：已有本地精选矢量时直接选用，不再让官网 PNG 覆盖品牌 SVG。没有本地矢量时，普通空间按需读取 `https://api.svgl.app` 全量公开目录，在本地按精确域名、产品路径匹配，优先下载目录 SVG；官网高清图片和本地应用图片作为后备。必要应用域名别名只匹配根品牌，不把子域名或相似域名套成母品牌。不向目录接口发送用户域名、完整网址或检索词。有本地应用图片后备时，在线发现最多等待 3 秒，且不向公共图标 API 披露域名。新收录品牌可以下载公开 SVG，经现有资源事务保存，无需发布新版扩展。

公开索引用 Zod 校验后缓存在已有 `browser.storage.local` 的 `raytab-public-brand-catalog` 项中，包含公开条目和刷新时间，不包含用户站点或私密内容。有效期七天，失败一小时后允许重试；缓存失败只保留本页内存并记录诊断，不能宣称索引已持久保存。索引不进入备份或同步，网站图片仍由 IndexedDB 资源入口保存。页面渲染与新标签页启动不请求在线目录；已保存图标不受上游目录变化影响。

普通空间新网站输入有效网址并离开字段时自动获取，私密空间仍由用户点击获取；手动选择、上传、裁切或关闭会使旧请求结果失效。官网网页图标与 PWA manifest 并行读取，后者只接受包含普通用途 `any` 的图标，不将仅用于蒙版或单色显示的图片直接作为普通图标。比较候选的真实尺寸、长宽比及矢量格式，不以第一张达到 128px 的图片结束选择；过宽横幅与内嵌位图的 SVG 不充当清晰图标。未知网站的官网、公开目录与 Vemetric API 并行准备，整个发现流程共用 8 秒预算；先选目录 SVG，再选官网高清图标，最后比较可用后备图片。64／96px 图片作为备用，原始 32px 仅在没有更清晰来源时保留。公共 API 只接收域名，先确认非占位图及原始尺寸，再从 API 本身下载图片，不从它返回的国外源站地址下载。

重新获取选择本地矢量时，会在草稿中清除原有自动图片引用，保存后由现有资源清理机制处理；手动底色保留。需要联网时重新验证 HTTP 缓存。获取失败时，已有图片与草稿保持不变；新结果不足 128px 且比当前图片更小时也不覆盖，并就近提示。本地应用图片的后备命中不能覆盖当前图片，也不报告为官网更新。保存失败继续保留本次图片草稿。

自动图标与本地矢量共用显示调整：以 128px 临时画布测量透明图形的实际边界、视觉面积与中心，限制最长边至图标框的 80%，按图形覆盖率平衡粗细与留白。测量只产生本组件的显示参数，不输出或保存栅格副本，不发起新的图标服务请求。带完整背景的应用图片铺满；测量不可用时使用固定留白。上传图片不自动调整。新裁切的自动图标记录 `fit: original`，重载、备份和同步保留该标记；恢复原图或重新获取后才重新应用自动调整。

Popup 在确认添加时复用同一获取与图片处理入口，网站和图标在同一事务保存。获取失败保留表单，可重试或明确选择文字占位继续；保存失败保留本次图片草稿，重试不会重复新增网站。关闭 Popup 后的旧获取结果不再保存。

图标按资源 ID 和实际写入版本共享读取与 Object URL，普通设置及位置保存不重新加载图片。资源写入通知相关页面刷新；恢复同一 ID 的不同图片也会失效。通知缺失或版本跳变时保守重读，私密会话锁定时立即撤销共享 URL。

默认不指定 API 的 `size` 参数。2026-10-03 核对官方[参数校验](https://github.com/vemetric/favicon-api/blob/main/src/lib/validators.ts)、[图片处理](https://github.com/vemetric/favicon-api/blob/main/src/lib/image-processor.ts)和实际下载发现，当前服务保留原像素，官网“默认 64px”的说明与实现不同；不能仅按说明强制请求放大图片。比较 JSON 元数据与下载后的真实尺寸，若服务缩小了可验证的原图，按原始尺寸有限重试；不接受超过原尺寸的上采样。小于 32px、损坏或服务占位图不使用；32px 是基本覆盖的最后回退，不称为高清。SVG 经过 XML 结构校验并成功解码后原样保存，保留 `image/svg+xml` 与矢量路径；不接受脚本、事件、动画、嵌入位图或外部资源依赖。备份、私密加密与同步沿用现有 Blob MIME 和字节编码，不另建格式或数据库。位图继续压缩为最大 256px WebP，不放大；用户明确裁切的结果仍输出 256px 以内的位图。找不到可用图片时显示就近错误，保留草稿，可以重新获取、使用文字或上传。未获取的网站只显示本地文字占位，不在渲染路径临时请求 favicon。

私密空间禁用在线目录与公共 API，IP、局域网／保留域名、非标准端口不发送第三方。仍无法仅凭域名判断企业分流 DNS；此类域名应放入私密空间。第三方能看见出口 IP，没有“零日志”承诺。公共服务的国内真实网络可用性未得到运营商实测；公开域名抽样与扩展内模拟源站失败只能证明当前环境结果和获取流程。

## 壁纸启动

轻量启动入口先应用普通空间底色、主题、背景来源和遮罩，再从现有 IndexedDB 数据库读取图片；下载 React 应用与读取、解码壁纸并行。缓存恢复后再挂载应用，背景 DOM 由同一个渲染器持续管理，React 不创建第二层背景。

数据库物理版本从 2 增加到 3，只新增可丢弃的 `wallpapers` 缓存表，不改写网站、已有图片或加密信封。在线缓存只保留最近成功的一张完整图片及平均底色；上传壁纸直接使用 `resources` 中原图，缓存表仅记录颜色。缓存不进入用户备份和同步，也不重复存缩略图或 BlurHash。

首张图片无淡入。资源加载、解码成功后才换图，加载失败保留当前已显示图片并通知用户。首屏没有缓存时使用协调底色；已缓存的在线图片可以离线启动，必应每日图跨日更新。启动缓存只来自已保存的普通空间，设置预览和私密背景不写入；跨空间切换立即清除上一空间图片，防止失败时残留私密壁纸。

新标签页仍受浏览器创建页面、读取磁盘和解码耗时影响，不承诺绝对零帧过渡。缓存写入失败会明确通知，不能把当前显示成功当成离线保存成功。

壁纸只响应相关显示字段和图片资源版本；上传图已解码且内容未变时复用。缓存写入失败仍可在页面重新聚焦或后续保存时重试，必应跨日更新保持不变。
