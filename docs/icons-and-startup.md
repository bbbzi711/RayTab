# 图标与壁纸启动

## 网站图标

网站／文字／上传仍是三种来源。已保存的自动图片、裁切结果和用户上传优先显示，不被本地或在线品牌素材覆盖。尚未获取的常用网站使用本地精选素材；透明像素显示在统一的不透明底色上，品牌原有颜色不会被背景色染色。未知网站使用统一中性底色，不按域名随机配色。

SVGL 社区目录完整生成本地索引，本次快照包含 667 条、565 个域名、827 个 SVG。国内常用网站另外从腾讯应用宝的结构化详情取得官方应用图片；带营销文字的图片改用官网长期标识（京东、拼多多、腾讯视频），按包名确认应用并记录发布者和素材，再接入同一品牌索引。目前覆盖 24 个域名、23 张官方素材（20 张 256px PNG、2 张官网 PNG、1 张 96px ICO），包括贴吧、京东、天猫、QQ邮箱、百度网盘、腾讯视频等；这不是全部网站的覆盖率承诺。完整应用图片按原有背景铺满图标，不再套缩小的 Logo 留白，也不显示对不透明图片无效的底色设置。常用品牌保留必要的默认底色和黑白对比处理；其他域名按目录的精确域名和产品路径匹配，不将任意子域名套成母公司图标。ChatGPT 等应用域名使用小型别名表，不维护重复的 Logo 库。

`public/brand-icons/catalog.json` 记录来源、品牌规范链接和 SHA-256；`third-party/svgl-LICENSE.txt` 保留上游许可，商标权归各自所有者。独立图片资源才进入目录，脚本、外部依赖等不收录。维护者运行 `node scripts/update-brand-icons.mjs` 更新离线快照；可用 `node scripts/update-brand-icons.mjs --apps-only` 只更新应用图片，映射记录在 `scripts/app-brand-sources.json`。应用素材记录包名、发布者、详情页、原图和哈希；商标权归发布者，不能按 SVGL 的许可重新授权。日常构建不联网；运行时不请求应用宝，也不需要自建服务器。

普通空间主动获取图标时，统一 `resolveWebsiteIcon` 入口按需读取 `https://api.svgl.app` 全量公开目录。索引在本地按精确域名、产品路径匹配；必要应用域名别名只匹配根品牌，不把子域名或相似域名套成母品牌。不向目录接口发送用户域名、完整网址或检索词。新收录品牌可以下载公开 SVG，经现有资源事务保存，无需发布新版扩展。

公开索引用 Zod 校验后缓存在已有 `browser.storage.local` 的 `raytab-public-brand-catalog` 项中，包含公开条目和刷新时间，不包含用户站点或私密内容。有效期七天，失败一小时后允许重试；缓存失败只保留本页内存并记录诊断，不能宣称索引已持久保存。索引不进入备份或同步，网站图片仍由 IndexedDB 资源入口保存。页面渲染与新标签页启动不请求在线目录；已保存图标不受上游目录变化影响。

普通空间新网站输入有效网址并离开字段时自动获取，私密空间仍由用户点击获取；手动选择、上传、裁切或关闭会使旧请求结果失效。取图和保存失败保留已有图片及草稿。未知网站通过站点网页／声明图标／PWA manifest 与 Vemetric 公共 API 在同一 8 秒预算内竞争。优先返回矢量或至少 128px 的原图；64／96px 图片作为备用；原始 32px 仅在更大来源均不可用时保留。合格高清图片返回后取消剩余工作。公共 API 只接收域名，先确认非占位图及原始尺寸，再从 API 本身下载图片，不从它返回的国外源站地址下载。

默认不指定 API 的 `size` 参数。2026-10-03 核对官方[参数校验](https://github.com/vemetric/favicon-api/blob/main/src/lib/validators.ts)、[图片处理](https://github.com/vemetric/favicon-api/blob/main/src/lib/image-processor.ts)和实际下载发现，当前服务保留原像素，官网“默认 64px”的说明与实现不同；不能仅按说明强制请求放大图片。比较 JSON 元数据与下载后的真实尺寸，若服务缩小了可验证的原图，按原始尺寸有限重试；不接受超过原尺寸的上采样。小于 32px、损坏或服务占位图不使用；32px 是基本覆盖的最后回退，不称为高清。SVG 保存时栅格化为最大 256px，位图不放大。找不到可用图片时显示就近错误，保留草稿，可以重新获取、使用文字或上传。未获取的网站只显示本地文字占位，不在渲染路径临时请求 favicon。

私密空间禁用在线目录与公共 API，IP、局域网／保留域名、非标准端口不发送第三方。仍无法仅凭域名判断企业分流 DNS；此类域名应放入私密空间。第三方能看见出口 IP，没有“零日志”承诺。公共服务的国内真实网络可用性未得到运营商实测；公开域名抽样与扩展内模拟源站失败只能证明当前环境结果和获取流程。

## 壁纸启动

轻量启动入口先应用普通空间底色、主题、背景来源和遮罩，再从现有 IndexedDB 数据库读取图片；下载 React 应用与读取、解码壁纸并行。缓存恢复后再挂载应用，背景 DOM 由同一个渲染器持续管理，React 不创建第二层背景。

数据库物理版本从 2 增加到 3，只新增可丢弃的 `wallpapers` 缓存表，不改写网站、已有图片或加密信封。在线缓存只保留最近成功的一张完整图片及平均底色；上传壁纸直接使用 `resources` 中原图，缓存表仅记录颜色。缓存不进入用户备份和同步，也不重复存缩略图或 BlurHash。

首张图片无淡入。资源加载、解码成功后才换图，加载失败保留当前已显示图片并通知用户。首屏没有缓存时使用协调底色；已缓存的在线图片可以离线启动，必应每日图跨日更新。启动缓存只来自已保存的普通空间，设置预览和私密背景不写入；跨空间切换立即清除上一空间图片，防止失败时残留私密壁纸。

新标签页仍受浏览器创建页面、读取磁盘和解码耗时影响，不承诺绝对零帧过渡。缓存写入失败会明确通知，不能把当前显示成功当成离线保存成功。
