# 导航改造与验收约定

## 已确认目标

- 当前定位为以网站图标管理为核心、简洁流畅的开源新标签页，功能取舍见 [产品定位](product-direction.md)。
- 首页延续壁纸、半透明表面、圆角搜索框和轻量字体的视觉语言；设置与编辑采用统一的中性表面和语义颜色。当前布局以 [界面基准](ui-reference.md) 为准，早期 raytab-home.html demo 仅作为历史参考。
- 左侧为标识、图标加名称的分组列表、添加分组；底部仅保留空间切换和设置。桌面侧栏 76px，窄屏 56px，窄屏仍保留左侧栏。
- 主内容始终按整个窗口居中，侧栏显隐不改变其定位，依次为时钟、日期、搜索、网站与手动文件夹。移除横向管理栏和常驻菜单工具；空白区域右键提供添加网站、新建文件夹、整理和设置。
- 分组内直接排列网站，文件夹由用户明确创建；不把所有旧分类自动变成文件夹。
- 直接拖动排序、移入/移出文件夹和跨组移动；右键编辑；批量模式需要明确进入。
- 新用户默认进入图标导航，简洁模式从首页右键切换；已有本地模式选择保留。
- 网站打开保存的原地址，不添加推广参数或跳转中间站。
- 保留首次加载 Hook 修复、已有数据、外观选择和私密空间保护。

## 当前数据接口

每个空间包含 groups、folders、sites、tombstones。实体保留 id、order、createdAt、updatedAt、changeId。

- Group：name。
- Folder：groupId、name；只支持一层，不自动嵌套。
- Site：groupId、folderId（首页为 null）、title、url、icon、iconBackground。
- icon 的 source 为 text、auto 或 resource，分别对应文字图标、网站图标、上传图片。text 保存 1–4 个 Unicode 字符，auto 可保存获取的网站图片 resourceId，resource 必须带上传图片 resourceId；不再提供 full/logo 显示模式。
- iconBackground 为 auto 或带 color 的自定义底色，当前运行路径使用实色背景；已有 transparent 数据在加载和导入边界转换为 auto。旧 color/iconId 只在明确的数据转换边界读取。
- 首页网站和文件夹共享排序；文件夹内的网站独立排序。
- 打开哪个分组和文件夹属于本地界面状态，不随远端排序强制切换当前视图。

命令延用 dispatch + repository.update 的单一写入口：

- save/select/move/delete-group；删除时指定内容接收组，至少保留一个组。
- save/select/move/delete-folder；删除文件夹仅解散容器，保留网站及相对顺序。
- save/delete/move-site；move-sites/delete-sites 校验整个批次后再改动。
- save-site 和 move-site 明确传入 groupId、folderId；目标文件夹必须属于目标组。
- 排序的 beforeId 指向目标容器内的真实条目；拖到自身不修改状态。
- 移动文件夹同时更新其中网站的 groupId。

## 数据安全与外观边界

- 不并行保留两套导航模型和 UI。旧本地数据采用一次性转换，保留原地址、图标和外观选择；加密数据仅在正确密码解密后转换。
- URL 仅做安全协议校验和必要的缺省协议补全，保留已有路径、查询参数和片段含义。
- 私密空间锁定时禁止修改私密内容；普通空间操作、备份和同步不能意外重新暴露或覆盖私密内容。
- 保存、备份、导入和同步必须使用同一模型，不能只让首页看起来能用。

## 验收证据

1. 首次打开与刷新正常，加载前后 Hook 顺序一致。
2. 实际浏览器中验证点击打开、右键、拖动排序、跨组移动、文件夹进出、批量取消及删除确认。
3. Enter 保持链接/按钮原生激活，Space 用于键盘拖动；拖动结束不能意外打开链接。
4. 修改位置、解散文件夹、删除分组后链接数量及 URL 不变；非法目标不产生部分修改。
5. 重启后状态保留，备份往返、私密空间及同步并发位置冲突有针对性测试。
6. 桌面与窄屏、长标题、大量分组、空文件夹、设置工作区和深浅主题实际检查；截图评审比例、间距、层级和动效。
7. pnpm 测试和 Chrome/Firefox 构建通过；检查 diff 清理本次废弃代码。

## 历史设置验收（2026-09-29）

- 侧栏三种模式下主页中心保持一致；完全隐藏不会被边缘悬停唤出。每行最多数量按实际空间适配，移除 840px 的额外上限。
- 时钟、日期、农历与问候语分别响应开关；自定义问候语和文字颜色生效。自动文字颜色考虑背景遮罩。
- 搜索引擎支持编辑，保存失败保留输入；私密空间继承列表变化后始终选用有效引擎，恢复与导出一致。
- 精选摄影使用独立地址，避免覆盖自定义壁纸；壁纸失败显示可读提示。
- 加密备份根据文件显示解密密码框；重复操作期间按钮禁用。同步连接有未保存改动时禁用手动同步；无扩展 API 的预览显示说明，避免原始 JavaScript 异常。
- 本次浏览器验证：三种侧栏模式中心均为 1280px 窗口的 640px；关闭时钟不隐藏日期/问候语；每行数量、标题与文字颜色生效；引擎编辑后刷新保留，实际搜索编码关键词且保留原参数；加密备份预览出现解密入口；320px 首页及设置面板无横向溢出。
- 真实同步服务仍需用户已有连接配置，本次没有发起远端覆盖或使用真实账号。

## 当前技术与界面（2026-10-03）

- 共享状态由 Zustand 管理，全部保存型表单使用 RHF/Zod，产品文案和语义错误使用 i18next，普通通知使用 Sonner，同步竞争使用原生 Web Locks。
- 网站图标优先使用本地社区品牌目录；普通空间按需刷新公开 SVGL 索引并在本地匹配，不向目录发送用户域名。未匹配网站同时尝试声明图标、PWA manifest 与公共 API，优先矢量或至少 128px 原图，64／96px 为备用，32px 原图仅作最后回退，小于 32px、损坏或服务占位图不使用。保存最大 256px，位图不放大；最终失败提供明确反馈并保留已有图片和草稿。私密空间和内网不走公共服务；未知网站未获取图标时显示本地文字占位。图片不额外增加 padding，图片默认白色实底、品牌图标使用品牌底色，文件夹使用实色底板；Popup 与编辑预览复用 SiteIcon。来源、隐私和缓存约定见 [图标与壁纸启动](icons-and-startup.md)。
- 图标底色提供十种常用颜色、自动及自定义；底色与彩色 Logo 的品牌原色分开，单色标记维持可读对比度。Gemini 使用本地打包的 Google 原始素材，避免误用 Google 搜索图标。
- 设置按任务分类，滑块预览与已保存数据分开，保留失败输入和栏目草稿。私密偏好通过一次确认整体恢复跟随普通空间，删除逐行继承说明与按钮；网站、分组和密码保护保留。
- 网站及文件夹只通过右键或 Shift+F10 / 菜单键操作，去除图标上的“…”；网站菜单只保留编辑网站、移动、删除。分组仍保留分组菜单入口，桌面空白和搜索／时钟菜单直接定位对应设置；输入框保留原生右键行为。
- 设置使用 840×640px 居中工作区；六类为通用、图标与布局、壁纸与主题、搜索与时钟、同步、数据与备份。语言、打开方式、分组栏与私密保护归入通用，窄屏分类保持可达，内容在同一滚动区展示。数据页先选择导入、导出或恢复任务，同步页按需展开连接表单。
- 网站外层背景底板及其设置删除，只保留图标自身的实色背景；旧透明底设置在现有校验边界转换为自动底色，保留图片和业务数据。图标编辑为 600px 弹窗，96px 预览置于图标区，只展开网站、文字、上传三种来源的当前参数。React Easy Crop 处理显式确认的手动裁切；白色和透明像素不会被自动抠除。
- 菜单共用主题样式，文件夹中心命中使用 dnd-kit 提供的稳定逻辑矩形。
- 当前运行模型为 state 5、backup 3；物理 IndexedDB 为 3，新增可丢弃的壁纸缓存表，AES 信封仍为 1。旧数据通过已知格式边界转换，不清库；启动缓存仅来自已保存普通空间，不包含私密或未保存预览。
- 当前验证、真实扩展运行环境和限制见[本轮验收记录](modernization-validation.md)。此前截图与开发预览属于历史记录，不代表本轮安装实例已更新。
