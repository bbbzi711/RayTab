# 导航改造与验收约定

## 已确认目标

- Gemini 负责前端方案和实现，协调者负责数据逻辑、接口和验收。
- 按已认可的 raytab-home.html demo 实现整体布局和交互；延续原项目壁纸、半透明表面、圆角搜索框和轻量字体的视觉语言。尺寸和动效可合理优化，保留视觉风格不等于保留旧布局。
- 左侧为标识、图标加名称的分组列表、添加分组；底部仅保留空间切换和设置。桌面侧栏 76px，窄屏 56px，窄屏仍保留左侧栏。
- 主内容始终按整个窗口居中，侧栏显隐不改变其定位，依次为时钟、日期、搜索、网站与手动文件夹。移除横向管理栏和常驻菜单工具；空白区域右键提供添加网站、新建文件夹、整理和设置。
- 分组内直接排列网站，文件夹由用户明确创建；不把所有旧分类自动变成文件夹。
- 直接拖动排序、移入/移出文件夹和跨组移动；右键编辑；批量模式需要明确进入。
- 网站打开保存的原地址，不添加推广参数或跳转中间站。
- 保留首次加载 Hook 修复、已有数据、外观选择和私密空间保护。

## 数据接口（已与 Gemini 前端方案核对）

每个空间包含 groups、folders、sites、tombstones。实体保留 id、order、createdAt、updatedAt、changeId。

- Group：name。
- Folder：groupId、name；只支持一层，不自动嵌套。
- Site：groupId、folderId（首页为 null）、title、url、color、可选 iconId。
- 首页网站和文件夹共享排序；文件夹内的网站独立排序。
- 打开哪个分组和文件夹属于本地界面状态，不随远端排序强制切换当前视图。

命令延用 dispatch + repository.update 的单一写入口：

- save/select/move/delete-group；删除时指定内容接收组，至少保留一个组。
- save/select/move/delete-folder；删除文件夹仅解散容器，保留网站及相对顺序。
- save/delete/move-site；move-sites/delete-sites 校验整个批次后再改动。
- save-site 和 move-site 明确传入 groupId、folderId；目标文件夹必须属于目标组。
- 排序的 beforeId 指向目标容器内的真实条目；拖到自身不修改状态。
- 移动文件夹同时更新其中网站的 groupId。

## 数据安全与外观边界

- 不并行保留两套导航模型和 UI。旧本地数据采用一次性转换，保留原地址、图标和外观选择；加密数据仅在正确密码解密后转换。
- URL 仅做安全协议校验和必要的缺省协议补全，保留已有路径、查询参数和片段含义。
- 私密空间锁定时禁止修改私密内容；普通空间操作、备份和同步不能意外重新暴露或覆盖私密内容。
- 保存、备份、导入和同步必须使用同一模型，不能只让首页看起来能用。

## 验收证据

1. 首次打开与刷新正常，加载前后 Hook 顺序一致。
2. 实际浏览器中验证点击打开、右键、拖动排序、跨组移动、文件夹进出、批量取消及删除确认。
3. Enter 保持链接/按钮原生激活，Space 用于键盘拖动；拖动结束不能意外打开链接。
4. 修改位置、解散文件夹、删除分组后链接数量及 URL 不变；非法目标不产生部分修改。
5. 重启后状态保留，备份往返、私密空间及同步并发位置冲突有针对性测试。
6. 桌面与窄屏、长标题、大量分组、空文件夹、设置抽屉和深浅主题实际检查；截图评审比例、间距、层级和动效。
7. pnpm 测试和 Chrome/Firefox 构建通过；检查 diff 清理本次废弃代码。

## 设置完善

- 侧栏三种模式下主页中心保持一致；完全隐藏不会被边缘悬停唤出。每行最多数量按实际空间适配，移除 840px 的额外上限。
- 时钟、日期、农历与问候语分别响应开关；自定义问候语和文字颜色生效。自动文字颜色考虑背景遮罩。
- 搜索引擎支持编辑，保存失败保留输入；私密空间继承列表变化后始终选用有效引擎，恢复与导出一致。
- 精选摄影使用独立地址，避免覆盖自定义壁纸；壁纸失败显示可读提示。
- 加密备份根据文件显示解密密码框；重复操作期间按钮禁用。同步连接有未保存改动时禁用手动同步；无扩展 API 的预览显示说明，避免原始 JavaScript 异常。
- 本次浏览器验证：三种侧栏模式中心均为 1280px 窗口的 640px；关闭时钟不隐藏日期/问候语；每行数量、标题与文字颜色生效；引擎编辑后刷新保留，实际搜索编码关键词且保留原参数；加密备份预览出现解密入口；320px 首页及设置面板无横向溢出。
- 真实同步服务仍需用户已有连接配置，本次没有发起远端覆盖或使用真实账号。
